## 用户操作：先验入口，再验业务

1. 打开 Codex 的“插件”页，确认「Jira 工作台 · 原生预览」存在且启用。若未刷新目录，保存工作后手工正常退出并从原始 Codex 图标重新打开。
2. 从官方全局入口打开工作台，再打开设置。确认不跳到本地浏览器、不遮挡当前聊天；工作台内设置在同页打开，返回后布局稳定。
3. 打开一个已有聊天，查看原生会话侧面板入口。确认能展开、收起并切换聊天，没有遗留遮罩。此步骤不创建或绑定新会话。
4. 首次使用在设置 UI 配置 Jira 连接并保存；本机已按用户明确要求复用旧连接，重新打开或刷新即可。检查回读、任务 / Sheets 目录、详情与父子单需求上下文；先不要执行状态流转或提交。
5. 新构建安装后检查图片原图清晰度、放大、原始尺寸和左右切换，以及父单 / 文档通过宿主导航至正确 Jira。非图片本地下载 / 打开仍为迁移缺口。检查暗色、窄面板和高 DPI 下没有溢出。
6. SVN 可先扫描、选择目录和文件、看差异、取消审核。实际提交另行明确确认；不要用生产提交证明安装可用。

出现问题请提供入口名称、操作步骤和脱敏截图，不提供 PAT、Token 或端点文件。无法自动观察或用户尚未确认的项目始终标为待验，不能静默回退到旧注入界面。

## 安装与恢复边界

持久源：`%LOCALAPPDATA%\jira-workbench\codex-native-plugin`。业务数据：`%LOCALAPPDATA%\jira-workbench\codex-native-preview`。两者独立，均不复用旧工作台目录。

安装器在注册前保存单独的 `config.toml` 备份；安装失败不自动用整份备份覆盖现有配置，避免丢失其他同时发生的修改。首次安装脚本不会升级、卸载、杀进程或重启。若要撤销，只处理该预览插件和该预览 Marketplace，保留业务数据；实际撤销需要另行明确选择。
